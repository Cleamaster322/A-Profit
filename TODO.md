## Правила дальнейшего ведения

1. В начале файла всегда отражаются закрытые задачи по датам.
2. Нельзя путать “сделано” и “план”.
3. Если задача закрыта, она переносится в журнал закрытых задач и не остаётся в активном списке.
4. Новые пункты добавляются только в актуальные главы.
5. Для каждой новой даты создаётся отдельный блок: “DD.MM.YYYY — N задач закрыто”.
6. В будущем можно вести историю по неделям, но минимум — по дням.
7. После закрытия большой вехи лучше добавлять один компактный итоговый пункт в журнал дат, а не перечислять всё по одному.
